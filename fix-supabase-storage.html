🔧 Fix: Supabase Storage - Email Logins Disabled

❌ Problema Identificado

Error: Email logins are disabled

Causa: Los logins por email están deshabilitados en tu proyecto de Supabase

Impacto: No se pueden subir imágenes a Supabase Storage porque requiere autenticación

🔧 Solución Principal: Habilitar Email Authentication

Paso 1: Ir al Dashboard de Supabase

Ve a: https://app.supabase.com/project/miwbzotcuaywpdbidpwo

Paso 2: Navegar a Authentication Settings

Authentication → Settings → Auth Providers

Paso 3: Habilitar Email Provider

  • ☑️ Buscar "Email" en la lista de providers
  • ☑️ Activar "Enable sign-ups"
  • ☑️ Activar "Enable email confirmations" (opcional)
  • ☑️ Guardar cambios

🔄 Workaround: Storage Público (Temporal)

Mientras habilitas email auth, puedes configurar storage público para permitir uploads sin autenticación.

Configurar Storage Público en Supabase

  1. Ve a Storage en el dashboard de Supabase
  2. Crear bucket "AVATARS" marcando como Public
  3. Configurar políticas RLS (ver código SQL abajo)

SQL para Políticas RLS:

-- Permitir uploads públicos al bucket AVATARS
CREATE POLICY "Allow public uploads to AVATARS" 
ON storage.objects FOR INSERT 
TO anon, authenticated 
WITH CHECK (bucket_id = 'AVATARS');

-- Permitir acceso público a archivos en AVATARS
CREATE POLICY "Allow public access to AVATARS" 
ON storage.objects FOR SELECT 
TO anon, authenticated 
USING (bucket_id = 'AVATARS');
