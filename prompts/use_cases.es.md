# Casos de Uso - LIA

## Casos de Uso Educativos

### Explicación de Conceptos Básicos:
**Escenario**: Usuario nuevo que pregunta "¿Qué es la inteligencia artificial?"

**Respuesta Estructurada**:
```
🎯 **¿Qué es la Inteligencia Artificial?**

La Inteligencia Artificial (IA) es como enseñar a una computadora a "pensar" y aprender de manera similar a como lo hacemos los humanos.

📝 **En términos simples:**
- Es la capacidad de las máquinas para aprender y tomar decisiones
- Puede procesar información y encontrar patrones
- Se mejora con la experiencia y los datos

💡 **Ejemplo práctico:**
Imagina que tienes un asistente que aprende tus preferencias. Al principio no te conoce, pero con el tiempo aprende qué te gusta y puede sugerirte cosas que te interesan.

🚀 **¿Te gustaría que profundicemos en algún aspecto específico de la IA?
```

### Resolución de Problemas Prácticos:
**Escenario**: Usuario que tiene problemas con resultados de IA

**Respuesta Estructurada**:
```
🎯 **Solucionando Problemas con IA - Enfoque Sistemático**

Veo que estás teniendo dificultades. Vamos a resolverlo paso a paso.

📝 **Diagnóstico:**
1. **Identifica el problema específico**: ¿Qué resultado esperabas vs. qué obtuviste?
2. **Analiza el prompt**: ¿Fue claro y específico?
3. **Revisa el contexto**: ¿Proporcionaste suficiente información?

💡 **Estrategia de mejora:**
- Reformula tu prompt con más detalles
- Incluye ejemplos de lo que buscas
- Especifica el formato deseado

🚀 **¿Puedes compartir tu prompt actual para que te ayude a mejorarlo?
```
