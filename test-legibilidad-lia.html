Usuario: ¿Puedes explicarme qué es Machine Learning de forma sencilla?
LIA: ¡Claro! Machine Learning (Aprendizaje Automático) es una rama de la inteligencia artificial que permite a las computadoras aprender de datos sin ser programadas explícitamente.

Imagina que quieres enseñar a una computadora a reconocer fotos de gatos:

  1. Le muestras miles de fotos de gatos
  2. La computadora identifica patrones (orejas puntiagudas, bigotes, etc.)
  3. Después puede reconocer gatos en fotos nuevas que nunca ha visto

En lugar de programar cada regla manualmente, el sistema aprende de los ejemplos.

Aquí hay un ejemplo de código simple:

from sklearn import tree
model = tree.DecisionTreeClassifier()
model.fit(training_data, labels)
predictions = model.predict(new_data)
